# SCOTOMA 0.1.0-alpha.1

Primera alpha cerrada para Android ARM64 y web.

> **Alpha experimental:** úsala únicamente para pruebas. No utilices SCOTOMA
> todavía para información sensible, diplomática, periodística, legal, médica
> o de alto riesgo.

- Web: <https://scotoma.pages.dev/>
- Android: `SCOTOMA-0.1.0-alpha.1-android-arm64.apk`
- Requisitos Android: Android 7.0/API 24 o superior y procesador ARM64.

## Qué se puede probar

- Encuentro de dos participantes mediante room y contraseña numéricas.
- Comparación del código corto de la sesión por un canal separado.
- Mensajes en ambos sentidos y ACK autenticado.
- BURN terminal sin historial ni reconexión automática.
- Interoperabilidad Android↔web y web↔web.

## Limitaciones conocidas

- El protocolo v2 todavía permite ataques de adivinación offline contra
  credenciales humanas débiles y no tiene revisión criptográfica independiente.
- Render, Cloudflare, el proveedor de Internet y otros observadores pueden ver
  metadatos como IP, horario, duración y volumen aproximado.
- Un sistema, teclado, navegador o dispositivo comprometido puede capturar el
  contenido antes o después del cifrado.
- El hosting gratuito puede dormir, reiniciarse o terminar una sesión.
- iPhone y Safari no están validados. ARMv7 y x86_64 no forman parte de esta
  distribución.

## Instalación y actualización

Descarga el APK únicamente desde este release y compara su SHA-256 antes de
instalar. Android puede pedir autorización para instalar aplicaciones desde el
navegador o gestor de archivos elegido. Las siguientes versiones se instalarán
sobre esta usando el mismo certificado oficial y un código de versión mayor.

No compartas room, contraseña y enlace de descarga por el mismo canal. Reporta
errores o vulnerabilidades mediante el canal privado indicado en `SECURITY.md`.
